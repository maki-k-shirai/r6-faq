## このドキュメントについて

正式版移行ユーザーの進捗を管理するスプレッドシートの使い方を説明します。営業が日常的に行う操作と、ステータスの見方を中心に解説します。

[正式版 進捗管理シートを開く](https://docs.google.com/spreadsheets/d/1_bqRujdlfTNg0XNRooeoYIDsPaMh9oLHQoFfGbXm-mY/edit?gid=0#gid=0)

---

## シートの構成

管理シートには以下の列があります。

| 列 | 内容 |
|---|---|
| 法人名 | 移行対象の法人名 |
| 担当営業 | 担当営業の氏名 |
| 移行希望年度 | 顧客から確認した移行予定年度 |
| ステータス | 現在の進捗状況（自動更新・手動更新あり） |
| 依頼日 | 正式版対応の依頼を受けた日付 |
| 科目整理 | マスタ班が科目整理完了時にチェック |
| 見積 | 有償・無償の区分 |
| 検収書 | 検収書受領時にチェック |
| 備考 | 経緯・特記事項など自由記入 |

---

## ステータスの意味

ステータスは以下の順で進みます。自動で更新されるものと、手動で更新するものがあります。

| ステータス | 意味 | 更新 |
|---|---|---|
| 未確認 | 移行希望年度が未確認。営業からの案内がまだ | 新規行追加時に自動セット |
| 未着手 | 移行希望年度は確認済。案内がまだ | 手動 |
| 依頼受付 | 依頼日が入力された | 自動 |
| 科目整理待ち | 科目一覧を送付済。顧客からの返答待ち | 手動（マスタ班） |
| 見積中 | 科目整理が完了。営業が有償・無償を判断する段階 | 自動 |
| コンバート作業中 | 見積確定。マスタ班がコンバート作業を進めている | 自動 |
| 確認待ち | 科目一覧を顧客に提示済。顧客からの確認待ち | 手動（マスタ班） |
| 科目確定済 | 顧客確認が取れた。マスタ班がメンテナンスを作成中 | 手動（マスタ班） |
| メンテナンス送付済 | メンテナンスを送付済。検収書の受領待ち | 手動（マスタ班） |
| 完了 | 検収書を受領済 | 自動 |

## 営業が行う操作

### 1. 移行希望年度を入力する

顧客から移行希望年度を確認したら、該当行の「移行希望年度」列に入力します。あわせてステータスを「未着手」→「依頼受付」に変更する準備をします。

### 2. 依頼日を入力する

顧客から正式版対応の依頼を受けたら、「依頼日」列に日付を入力します。

**入力すると自動で以下が実行されます。**

- ステータスが「依頼受付」に変わる
- マスタ班（tk-mms@maki.ne.jp）に依頼受付の通知メールが送信される
- 通知は1回のみ送信されます（重複送信はしません）

### 3. 見積区分を入力する

マスタ班から科目整理完了の通知が届いたら、「見積」列に「有償」または「無償」を選択します。

**入力すると自動で以下が実行されます。**

- ステータスが「コンバート作業中」に変わる
- マスタ班に見積確認の通知メールが送信される
- 通知は1回のみ送信されます（値を変更しても再送はしません）

> 見積区分を変更する必要がある場合は、マスタ班に直接連絡してください。自動通知は再送されません。

### 4. 備考を記入する

顧客との経緯や特記事項は「備考」列に記入します。日付を先頭に入れておくと後から確認しやすくなります。

**記入例：**

2026/05/01 令和8年度から9年度に変更と連絡あり

## よくある操作

### 移行希望年度が変わった場合

「移行希望年度」列を直接書き換えます。あわせて備考に変更の経緯を記録しておいてください。

### 移行しないことが決まった場合

ステータスを手動で「未確認」に戻し、備考に「移行しない」と経緯を記録します。移行希望年度は「移行しない」と入力してください。

### 新しい法人を追加する場合

新しい行を追加すると、ステータスが自動で「未確認」にセットされます。法人名・担当営業を入力してください。
