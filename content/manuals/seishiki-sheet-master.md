## このドキュメントについて

正式版移行ユーザーの進捗を管理するスプレッドシートの使い方を説明します。マスタ班が行う手動操作と、内部管理シートの更新方法を中心に解説します。

[正式版 進捗管理シートを開く](https://docs.google.com/spreadsheets/d/1_bqRujdlfTNg0XNRooeoYIDsPaMh9oLHQoFfGbXm-mY/edit?gid=0#gid=0)

---

## シートの構成

### 管理シート（営業・マスタ班共用）

進捗状況を管理するメインのシートです。

| 列 | 内容 |
|---|---|
| 法人名 | 移行対象の法人名 |
| 担当営業 | 担当営業の氏名 |
| 移行希望年度 | 顧客から確認した移行予定年度 |
| ステータス | 現在の進捗状況 |
| 依頼日 | 正式版対応の依頼を受けた日付 |
| 科目整理 | 科目整理完了時にチェック（マスタ班が操作） |
| 見積 | 有償・無償の区分（営業が入力） |
| 検収書 | 検収書受領時にチェック（マスタ班が操作） |
| 備考 | 経緯・特記事項など自由記入 |

### 内部管理シート（マスタ班・GAS専用）

担当者情報と通知フラグを管理するシートです。通常は非表示になっています。

| 列 | 内容 |
|---|---|
| 法人名 | 管理シートの法人名と一致させる |
| 担当者 | 顧客側の担当者氏名 |
| アドレス | 顧客側の担当者メールアドレス |
| 依頼日通知済 | 依頼受付メールの送信済フラグ |
| 科目整理通知済 | 科目整理完了メールの送信済フラグ |
| 見積通知済 | 見積確認メールの送信済フラグ |

## ステータスの意味と更新タイミング

マスタ班が手動で更新するステータスは以下です。

| ステータス | 更新タイミング |
|---|---|
| 未着手 | 移行希望年度を営業から確認できたとき |
| 科目整理待ち | 顧客に科目一覧を送付したとき |
| 確認待ち | 科目一覧を顧客に提示したとき |
| 科目確定済 | 顧客から科目の確認が取れたとき |
| メンテナンス送付済 | メンテナンスを顧客に送付したとき |

以下は自動更新のため、マスタ班が手動で変更する必要はありません。

| ステータス | 自動更新のトリガー |
|---|---|
| 未確認 | 新規行追加時 |
| 依頼受付 | 依頼日入力時 |
| 見積中 | 科目整理チェック時 |
| コンバート作業中 | 見積区分入力時 |
| 完了 | 検収書チェック時 |

## マスタ班が行う操作

### 1. 科目整理が完了したらチェックする

科目一覧が顧客から戻ってきて科目数を確認したら、「科目整理」列のチェックボックスをONにします。

**チェックすると自動で以下が実行されます。**

- ステータスが「見積中」に変わる
- 担当営業に科目整理完了の通知メールが送信される
- 通知は1回のみ送信されます

あわせて「科目数」列に科目数を入力してください。通知メールに科目数が記載されます。

### 2. 科目一覧を送付したらステータスを更新する

顧客に科目一覧を送付したら、ステータスを手動で「科目整理待ち」に変更します。

### 3. 作業が進んだらステータスを更新する

以下のタイミングで手動でステータスを更新してください。

| タイミング | 変更後のステータス |
|---|---|
| 顧客に科目一覧を提示した | 確認待ち |
| 顧客から科目の確認が取れた | 科目確定済 |
| メンテナンスを送付した | メンテナンス送付済 |

### 4. 検収書を受領したらチェックする

検収書を受領したら「検収書」列のチェックボックスをONにします。ステータスが自動で「完了」になります。

### 5. 備考を記入する

作業の経緯や特記事項は「備考」列に記入します。日付を先頭に入れておくと後から確認しやすくなります。

**記入例：**

2026/05/01 金融資産Excelを送付。返答待ち

## 内部管理シートの更新

### 担当者・アドレスを更新する場合

1. 内部管理シートを表示する（シート名タブを右クリック→「再表示」）
2. 該当法人の行を探す
3. 「担当者」「アドレス」列を更新する
4. 更新後はシートを非表示に戻す

担当者・アドレスは依頼受付メールのreplyToに使用されます。空欄でも通知は送信されますが、返信先が設定されません。

### 通知を再送したい場合

通常、各通知は1回のみ送信されます。再送が必要な場合は以下の手順で対応してください。

1. 内部管理シートを表示する
2. 該当法人の行を探す
3. 再送したい通知のフラグ列（依頼日通知済・科目整理通知済・見積通知済）を「FALSE」に変更する
4. 管理シートで該当のトリガー操作を再度行う（依頼日の再入力・チェックボックスのOFF→ON）
